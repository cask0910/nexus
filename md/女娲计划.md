## Git 协作（`git化方案` v2 现行 · 09-10 补 §9.0）

- 笔记本本机 = main 稳定 + `local/*` 分支；**Cask = `cask/*` 工作分支，不直接推 main**；其他 AI 提本地 main 等她推
- Cask 工作流：`git fetch --prune` → main `pull --ff-only` → `cask/<任务短名>` → 完成后 push 工作分支等审
- 提交按「一件事」分（跨目录也算一件）· 默认完成即推、周末兜底 · `origin` 走 SSH
- 冲突保留双方内容并核对时间与来源 · 不 force push · DOCX/录音/视频等大型材料**不进 Git**（笔记本留存）；文本/代码/运行状态以远程已确认提交为共同事实源
